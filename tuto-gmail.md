# Tutoriel Web3Forms pour Gmail

Ce guide explique comment configurer Web3Forms pour que les formulaires du site arrivent sur l'adresse Gmail :

`oneurosens.formation@gmail.com`

L'objectif est simple :

1. se connecter a Web3Forms avec l'adresse Gmail
2. creer un formulaire
3. recuperer la cle publique `Access Key`
4. me transmettre cette cle

Je m'occupe ensuite du reste sur le site.

## Avant de commencer

Il vous faut :

1. l'acces a la boite Gmail `oneurosens.formation@gmail.com`
2. un navigateur web
3. 5 minutes environ

## Etape 1 - Se connecter avec le bon compte Gmail

Important :

Il faut faire cette manipulation en etant connecte avec `oneurosens.formation@gmail.com`.

Si vous etes connectee avec une autre adresse :

1. ouvrez une fenetre de navigation privee, ou
2. deconnectez-vous de l'autre compte avant de commencer

Ensuite :

1. ouvrez `https://web3forms.com/`
2. cliquez sur le bouton pour vous connecter ou demarrer
3. choisissez la connexion avec Google si elle est proposee
4. selectionnez bien le compte `oneurosens.formation@gmail.com`

## Etape 2 - Creer le formulaire

Quand Web3Forms demande de creer un formulaire :

1. dans `Form Name`, mettez par exemple :
   `O Neuro Sens - Contact`
2. dans `Domain name`, mettez :
   `oneurosens.fr/contact`
3. cliquez sur `Create Form`

Si Web3Forms accepte aussi `localhost`, ce n'est pas utile ici.
Le plus simple est d'indiquer directement le domaine du site.

## Etape 3 - Recuperer la cle

Une fois le formulaire cree, Web3Forms affiche un ecran avec :

`Form Access Key`

Cette cle ressemble a une suite de lettres, chiffres et tirets, par exemple :

`xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`

Ce qu'il faut faire :

1. cliquez sur l'icone de copie a droite de la cle
2. collez cette cle dans un email ou un message
3. envoyez-la moi

## Etape 4 - Ce qu'il faut me transmettre

Merci de me communiquer uniquement ces informations :

1. l'adresse Gmail utilisee :
   `oneurosens.formation@gmail.com`
2. la `Web3Forms Access Key`

Exemple de message a m'envoyer :

```text
Adresse Gmail utilisee : oneurosens.formation@gmail.com
Web3Forms Access Key : xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

## Ce qu'il ne faut pas m'envoyer

Ne m'envoyez pas :

1. le mot de passe Gmail
2. les codes recus par SMS
3. un code Google de verification
4. des captures avec d'autres informations personnelles visibles si ce n'est pas necessaire

La seule information technique dont j'ai besoin est la `Access Key`.

## Si Web3Forms affiche deja un formulaire

Si un formulaire existe deja dans le compte Gmail, vous pouvez :

1. ouvrir le tableau de bord Web3Forms
2. ouvrir le formulaire deja cree, ou
3. en creer un nouveau

Dans les deux cas, il faut me transmettre la `Access Key` du formulaire rattache au compte Gmail.

## Verification simple

Avant de m'envoyer la cle, verifiez simplement :

1. que vous voyez bien l'adresse `oneurosens.formation@gmail.com` dans Web3Forms, et
2. que vous avez bien copie la ligne `Form Access Key`

## En cas de blocage

Si vous etes bloquee, envoyez-moi une capture de l'ecran bloque et dites-moi a quelle etape vous etes :

1. connexion Gmail
2. creation du formulaire
3. copie de la cle

Avec cela, je pourrai vous guider tres rapidement.
